Healthcare Analytics & Risk Prediction

A cloud-native healthcare analytics platform demonstrating the complete path from stored healthcare data to machine-learning predictions served through scalable cloud services.

GCP · PYTHON · TERRAFORMPRODUCTION-STYLE ARCHITECTURECLOUD RESOURCES ARCHIVED AFTER DEVELOPMENT

The problem

Healthcare data becomes useful when organizations can reliably process it, train models on it, and make predictions available to downstream applications. This project treats that full systems problem rather than the model as an isolated notebook.

Architecture

Healthcare Data→Cloud Storage / BigQuery→ML Processing→Vertex AI→Cloud Run REST API

Terraform preserves the infrastructure definition so the environment can be recreated without keeping paid resources running continuously.

What I built

  • Cloud-native analytics and ML workflow
  • Patient health-risk prediction with Python and scikit-learn
  • REST API services through Cloud Run
  • Infrastructure as Code with Terraform
  • Docker containerization and cloud logging

Engineering choices

I treated deployment as part of the project, not an afterthought. Containerization, infrastructure provisioning, API serving, storage, and model infrastructure are represented alongside the ML code.

The live resources were intentionally shut down after development to avoid ongoing GCP charges. The repository retains the deployment and Terraform configuration.
