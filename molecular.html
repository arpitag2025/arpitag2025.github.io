Molecular Activity Prediction

A machine-learning pipeline for predicting molecular pIC50 while searching for compact, useful subsets among hundreds of chemical descriptors.

385 DESCRIPTORSMULTIPLE LINEAR REGRESSIONGENETIC-ALGORITHM-INSPIRED SEARCH

The problem

Molecular datasets can contain hundreds of descriptors. Using every descriptor can increase complexity and introduce weak features, so this project asks whether smaller subsets can retain useful predictive information.

Pipeline

Raw Data→Clean + pIC50→Standardize→Feature Subsets→MLR→Validation

Feature search

Candidate models are represented as binary vectors identifying selected descriptors. An initial population of 50 candidates is evaluated, stronger candidates become parents, and crossover generates new feature combinations while random candidates preserve diversity.

Evaluation

  • R² for training fit
  • Q² using leave-one-out cross-validation
  • Validation predictive R²
  • Test predictive R² on unseen data
  • Fitness score balancing prediction error and model complexity
