Mushroom Toxicity Classification

An experiment asking whether mushroom toxicity can be predicted reliably from visual appearance alone.

RESNET50 · YOLOV8IMAGE CLASSIFICATIONRESULT: APPEARANCE ALONE WAS NOT RELIABLE

Question

The project tests whether visual features in mushroom images contain enough information to distinguish poisonous from non-poisonous mushrooms.

Approach

We explored the image data and trained multiple classification approaches, including ResNet50 and YOLOv8.

Images→EDA / Preprocessing→Classification Models→Evaluation

Result

The experiment supported the original hypothesis: visual appearance alone was not a dependable toxicity indicator. Tested models reached roughly 50–70% accuracy.

The useful result is the limitation itself. A model can answer a research question even when the answer is that the available signal is insufficient.

Takeaway

This work reinforced the importance of dataset structure, class quality, validation, and interpreting performance in the context of the underlying research question.
